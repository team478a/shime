# SHIME 参加者操作マニュアル

更新日: 2026-07-31  
対象: SHIME 2026-08-08版  
想定端末: LINEを利用できるスマートフォン

## 1. はじめに

SHIMEは、イベント申込、LINE本人連携、事前準備、当日受付、席案内、
希望入力、結果確認をスマートフォンで行うサービスです。

イベントによって使用する機能と順番が異なります。
画面上部の案内と、主催者から届いたLINEメッセージに従ってください。

本イベントの必須導線にオンライン決済は含まれません。

## 2. ご用意いただくもの

- LINEを利用できるスマートフォン
- 主催者から案内された申込URLまたはLINE案内
- 申込時に入力した電話番号または生年月日
- 当日、受付で提示できるスマートフォン

管理画面へのログインは必要ありません。

## 3. 安全に利用するために

- 主催者から届いた正規のURLを開いてください。
- 本人連携URLや受付QRを他の人へ転送しないでください。
- LINE本人連携は、参加するご本人のLINEアカウントで行ってください。
- 公共の端末や他人のスマートフォンで操作しないでください。
- 不審なURLや、パスワード・認証コードを求める連絡は主催者へ確認してください。

## 4. 申込み

1. 主催者から案内された申込URLを開きます。
2. イベント概要と参加条件を確認します。
3. 申込情報を入力します。
4. イベント規約とプライバシーポリシーをそれぞれ開きます。
5. 内容を確認して同意します。
6. 入力内容の確認画面へ進みます。
7. 「申込みを確定」を押します。
8. 「申込みを受け付けました」と表示されることを確認します。

送信中にボタンを何度も押さないでください。
エラーが表示された場合は、入力内容と通信状態を確認してから再度お試しください。

## 5. LINE本人連携

申込み完了後、続けて本人連携を行います。

1. 「LINEで本人連携へ」を押します。
2. LINEの認証画面が表示された場合は内容を確認します。
3. 申込時の電話番号下4桁、または生年月日を入力します。
4. 「本人連携」を押します。
5. 「本人連携が完了しました」と表示されることを確認します。

同じスマートフォンで操作する場合、QRを読み取る必要はありません。

### 本人連携できない場合

- LINEアプリ内で開いているか確認します。
- 申込時と同じ電話番号下4桁または生年月日を入力します。
- URLの有効期限が切れている場合は、主催者へ再発行を依頼します。
- 一度使用済みのURLは再利用できません。
- すでに連携済みの場合は、連携したLINEアカウントから開き直します。

## 6. 参加準備画面

本人連携後は、主催者から届くLINE案内からSHIMEを開きます。
ブラウザへ直接URLを入力するのではなく、LINEの案内から開くことを推奨します。

画面上部には、イベントで利用するステップが表示されます。
例:

- Dream
- 席案内5問
- SHIME診断
- SHIME PASS
- 希望入力
- 結果

実際の順序はイベント設定に従います。

## 7. Dream

Dreamは、今の気持ちや大切にしたいことを整理するための機能です。

1. 感情カードから今の気持ちに近いものを選びます。
2. 画面の質問に沿って入力します。
3. 表示された候補を選択するか、ご自身で編集します。
4. 公開範囲を選びます。
5. 内容を確認して確定します。

イベント設定が任意の場合は、後で登録する、またはスキップできます。
公開範囲を「非公開」にしたDreamは他の参加者へ表示されません。
プロジェクト参加などの任意項目は、選択しなくてもイベントへ参加できます。

通信エラーが表示された場合は、接続を確認してから再度操作してください。

## 8. 席案内5問

1. 各質問の選択肢から回答を選びます。
2. 回答しづらい場合は、用意されている「答えたくない」を選べます。
3. 途中で止める場合は「途中保存」を押します。
4. 5問の内容を確認します。
5. 「提出」を押します。

回答は席配置の計算に使用され、他の参加者には公開されません。
通信に失敗した場合は、再度開いて保存済みの回答を確認してください。

## 9. SHIME診断

イベントでSHIME診断が有効な場合だけ表示されます。

1. 「SHIME診断を始める」を押します。
2. 裏向きのカードから、今の気持ちに近い1枚を選びます。
3. 選んだカードの内容を確認します。
4. 4つの質問へ回答します。
5. 「確認へ進む」を押します。
6. 回答内容を確認して提出します。
7. 表示された結果を確認します。

選択前にカードの表面情報は表示されません。
回答と結果は他の参加者には公開されません。
この結果は自己理解を支援するもので、性格、相性、医学的・心理学的状態を
断定するものではありません。

診断期間外または利用できない場合は、主催者へご確認ください。

## 10. SHIME PASS

Dreamや席案内5問など、イベントで必要な事前準備が終わると
SHIME PASSを発行できます。

1. 「SHIME PASSを発行」を押します。
2. 参加者番号と準備状況を確認します。
3. 当日は「受付QRを表示」を押します。

事前準備が不足している場合は、先に必要なステップを完了するよう案内が表示されます。

### 受付QR

- QRには氏名や電話番号は直接含まれません。
- 「QRを再発行」すると、それまでのQRは使用できなくなります。
- QRには有効期限があります。
- 必要に応じて、QR画像を別画面で開く、保存する、受付コードをコピーできます。
- QRや受付コードをSNSや他の参加者へ送らないでください。

## 11. 当日受付

1. LINEの案内からSHIME PASSを開きます。
2. 「受付QRを表示」を押します。
3. スタッフへQRを提示します。
4. スタッフの確認が終わるまで画面を閉じずに待ちます。
5. 受付済み表示と受付番号を確認します。

QRを表示できない場合は、参加者番号をスタッフへ伝えてください。
スタッフが氏名の一部または参加者番号の先頭文字で検索し、本人確認後に手動受付できます。

受付QRを見せただけでは受付確定にならない場合があります。
スタッフから受付完了の案内を受けてください。

## 12. 席の確認

運営責任者が席配置を公開すると、ご本人のテーブルと席だけが表示されます。

- 他の参加者の回答やDreamは表示されません。
- 公開前は「準備中」と表示される場合があります。
- 席変更の案内があった場合は、画面を再読み込みして最新情報を確認します。

画面に席が表示されない場合は、受付状態を確認してスタッフへお尋ねください。

## 13. 希望入力

希望入力期間中に、イベントで実際に会話した候補が表示されます。

1. 「またお話ししたい方」を開きます。
2. 希望する方を選びます。
3. 順位方式の場合は、選んだ順が順位になります。
4. 必要に応じて、運営だけが確認する任意メモを入力します。
5. 途中で止める場合は「途中保存」を押します。
6. 「この内容で提出」を押します。

希望する方がいない場合は、「今回は選ばず提出」を選べます。
締切までは変更できる場合があります。

選択内容、順位、任意メモ、一方だけの希望は相手へ公開されません。

## 14. 結果確認

運営責任者が内容を確認して確定した後、結果を確認できます。

1. LINEの案内から「結果」を開きます。
2. 「イベントからのご案内」を確認します。

確定前は「ご案内はまだ準備中です」と表示されます。
成立時の連絡先交換は、イベント設定に従って運営から案内されます。
画面表示だけをもとに、相手の個人情報を探したり連絡したりしないでください。

## 15. よくあるトラブル

### 「イベント情報を確認できませんでした」

- LINEの案内から開き直してください。
- 以前保存した古いURLではなく、最新の案内を使用してください。
- 改善しない場合は主催者へ連絡してください。

### 「処理を完了できませんでした」

- 通信状態を確認します。
- ボタンを連打せず、少し待ってから再度開きます。
- 保存済み内容が残っているか確認します。

### LINEではなく通常ブラウザで開いた

本人認証が必要な画面は、LINEアプリ内の案内から開き直してください。

### QRが表示されない

- 画面を再読み込みします。
- 「QRを再発行」を1回だけ押します。
- 表示できない場合は参加者番号による手動受付を利用します。

### ステップが表示されない

イベントによって利用しない機能があります。
利用期間外、または前の必須ステップが未完了の可能性もあります。
主催者へご確認ください。

## 16. 主催者へ問い合わせる際の情報

次を伝えると確認がスムーズです。

- イベント名
- 発生した日時
- 画面に表示されたエラーメッセージ
- どのボタンを押した時に発生したか
- 使用端末（iPhone／Android）
- LINEアプリ内か、通常ブラウザか

パスワード、本人連携URL、受付QR、受付コード、電話番号、生年月日を
一般のチャットへ送らないでください。

## 17. プライバシー

- 申込情報は本人確認とイベント運営に使用されます。
- 席案内5問の回答は他の参加者へ公開されません。
- SHIME診断の回答と結果は他の参加者へ公開されません。
- 一方希望、順位、任意メモは相手へ公開されません。
- 非公開に設定したDreamは他の参加者へ公開されません。
- 結果は運営責任者の確認後にだけ表示されます。

詳細は、申込時に表示されるイベント規約とプライバシーポリシーをご確認ください。

# SHIME クライアント確認ガイド

更新日: 2026-07-31

対象: 2026年8月8日イベントの画面・導線確認

この確認は、クライアントと開発側が本番導線を早期に確定するためのUATです。
**担当者から案内されたUAT専用イベントと合成参加者だけを使用し、実参加者情報は入力しないでください。**

## はじめての方へ

UATとは「本番前に、実際の利用者と同じ順番で画面を操作し、内容が正しいか確認する作業」です。
難しい技術確認は必要ありません。次の3点を見つけることが目的です。

- 操作方法が分からない画面
- 表示内容や順番が想定と違う画面
- ボタンを押しても先へ進めない画面

迷った場合も失敗ではありません。**迷った場所そのものが重要な改善情報**です。

### 用意するもの

- PCまたはタブレット1台: 運営管理画面用
- LINEが使えるスマートフォン1台: 参加者画面用
- 画面を記録するメモまたはスクリーンショット
- 30〜60分程度の時間

端末が1台だけでも確認できます。その場合は、管理画面とLINE画面を交互に開いてください。

### 使用するURL

- 管理者ログイン: [https://app.shimelife.jp/admin/login](https://app.shimelife.jp/admin/login)
- クライアント確認ガイド: [https://app.shimelife.jp/admin/manual/uat](https://app.shimelife.jp/admin/manual/uat)
- UAT専用申込フォーム: [https://app.shimelife.jp/apply/d4e9b3eb-67e0-4ce5-879d-98934b0f055f](https://app.shimelife.jp/apply/d4e9b3eb-67e0-4ce5-879d-98934b0f055f)

ログイン情報は運営責任者から個別に受け取ってください。本資料にはパスワードを記載しません。

## 初心者向けステップ・バイ・ステップ

### ステップ0: UAT専用イベントを確認する

1. PCで管理者ログインURLを開きます。
2. テナントコード、ログインID、パスワードを入力します。
3. 「ログイン」を押します。
4. 管理画面に`[UAT専用] SHIME Client UAT`と表示されていることを確認します。
5. 別の正式イベントが表示された場合は、操作せず運営責任者へ連絡します。

確認すること:

- [ ] UAT専用と明記されている
- [ ] 本番参加者の名前が表示されていない
- [ ] スマートフォンでもメニューを開ける

### ステップ1: 参加者として申し込む

1. スマートフォンでUAT専用申込フォームを開きます。
2. 画面上部のイベント名に`UAT専用`と表示されていることを確認します。
3. 氏名には`UAT確認01`など、実在しないテスト名を入力します。
4. 電話番号、生年月日、メールアドレスも、運営から指定された合成値だけを入力します。
5. 規約・プライバシーポリシーを開き、読みやすさを確認します。
6. 同意欄を確認して申込ボタンを押します。
7. 「申込みを受け付けました」などの完了表示を確認します。
8. 入力した電話番号の下4桁または生年月日をメモします。本人連携で使用します。

確認すること:

- [ ] 何を入力すればよいか分かる
- [ ] 必須項目が分かる
- [ ] 規約を申込前に確認できる
- [ ] 完了したことが明確に分かる

ここで先へ進めない場合は、同じ申込を何度も送信せず、画面のスクリーンショットを保存してください。

### ステップ2: 管理画面で申込者を見つける

1. PCの管理画面へ戻ります。
2. 対象イベントの「参加者・LINE連携」を開きます。
3. 検索欄へ`UAT確認`など氏名の一部を入力します。
4. 先ほどの申込者だけが候補に表示されることを確認します。
5. 表示されない場合は、ページを一度更新して再検索します。

確認すること:

- [ ] 氏名の一部だけで検索できる
- [ ] 候補者を間違えにくい
- [ ] 未連携であることが分かる

### ステップ3: LINE本人連携リンクを発行する

1. 対象参加者の「リンクを再発行」を押します。
2. 緑色の「再発行済み」表示を確認します。
3. 「リンクをコピー」を押します。
4. コピーしたURLを、確認に使う本人のスマートフォンへ安全に渡します。
5. URLは対象本人以外へ送らないでください。

確認すること:

- [ ] どの参加者のリンクか分かる
- [ ] 有効期限が分かる
- [ ] コピー完了が分かる

### ステップ4: スマートフォンでLINE本人連携する

1. スマートフォンのLINEで本人連携URLを開きます。
2. イベント名と「LINE本人連携」の表示を確認します。
3. ステップ1でメモした電話番号下4桁または生年月日を入力します。
4. 「本人連携」を押します。
5. 「本人連携が完了しました」と表示されることを確認します。
6. 「Dreamへ進む」を押します。

確認すること:

- [ ] 誰の、どのイベントの連携か分かる
- [ ] 本人確認の入力方法が分かる
- [ ] 連携完了後の次の操作が分かる

何度も失敗すると一時的に操作が制限される場合があります。2回失敗したら入力を止めて運営へ連絡してください。

### ステップ5: Dreamを登録する

1. Dream画面の説明を読みます。
2. テスト用の内容を入力します。実際の悩みや個人情報は入力しません。
3. 候補を表示します。
4. 表示された候補から1つ選びます。
5. 登録完了表示を確認します。
6. 「次へ進む」を押します。

確認すること:

- [ ] Dreamの目的が分かる
- [ ] 入力から候補選択まで迷わない
- [ ] 非公開範囲が分かる
- [ ] 完了後の次の操作が分かる

### ステップ6: 席案内5問に回答する

1. 5問すべての質問と選択肢を読みます。
2. テスト回答を選びます。
3. 答えたくない場合の選択肢が適切か確認します。
4. 「次へ進む」を押します。
5. 回答提出の完了表示を確認します。

確認すること:

- [ ] 質問文が分かりやすい
- [ ] 選択肢に不足や違和感がない
- [ ] スマートフォンで押しやすい
- [ ] 回答負担が大きすぎない

### ステップ7: SHIME PASSと受付QRを確認する

1. SHIME PASS画面を開きます。
2. 「SHIME PASSを発行」を押します。
3. 参加者番号が表示されることを確認します。
4. 「受付QRを表示」を押します。
5. QRがスマートフォンの画面内に表示されることを確認します。
6. QRが表示できない場合は、受付コードをコピーできることを確認します。

確認すること:

- [ ] 参加者番号が見つけやすい
- [ ] 当日見せる画面が分かる
- [ ] QRが大きく表示される
- [ ] QRが使えない場合の代替方法が分かる

### ステップ8: 運営スタッフとして受付する

1. PCの管理画面で対象イベントの「受付」を開きます。
2. 参加者番号の先頭1文字、番号、または氏名の一部で検索します。
3. 対象者を選びます。
4. 氏名と参加者番号を確認します。
5. 「受付を確定」を押します。
6. 受付番号が表示されることを確認します。
7. 同じ人を再度受付しようとした場合、受付済みと分かることを確認します。

確認すること:

- [ ] 少ない文字で候補を検索できる
- [ ] 別の参加者と間違えにくい
- [ ] 受付完了と受付番号が分かる
- [ ] 二重受付を防止できる

### ステップ9: 席配置を作成して公開する

この確認には、異なる参加区分の受付済み合成参加者が2名以上必要です。1名だけの場合は運営責任者へ準備を依頼してください。

1. 管理画面で「席配置」を開きます。
2. 受付済み人数を確認します。
3. 「新しい配置案を生成」を押します。
4. 各参加者のテーブルと席を確認します。
5. 必要に応じて席を変更します。
6. 確定させたい席は「この席をロック」にチェックします。
7. 「変更を保存」を押します。
8. 内容を再確認して「内容を確認して公開」を押します。

`CATEGORY_PAIR_CONFLICT`が表示された場合は、必要な参加区分の相手が不足しています。何度も保存せず、参加者構成を確認してください。

確認すること:

- [ ] 誰がどの席か図で分かる
- [ ] 未配置の参加者が分かる
- [ ] 保存と公開の違いが分かる
- [ ] 公開前に最終確認できる

### ステップ10: 参加者のPASSで席を確認する

1. スマートフォンでSHIME PASSへ戻ります。
2. 「席案内を更新」を押します。表示が古い場合はLINEを閉じて開き直します。
3. テーブル番号と席番号が表示されることを確認します。
4. 管理画面で公開する前には席が見えないことも確認します。

確認すること:

- [ ] 自分の席だけが表示される
- [ ] テーブルと席を見間違えにくい
- [ ] 未公開時に「準備中」と分かる

### ステップ11: 希望入力と結果確認を行う

この操作は、運営責任者から「希望入力を開始しました」と案内された後に行います。

1. スマートフォンで「希望」へ進みます。
2. 候補者と選択上限を確認します。
3. テスト用の希望を入力して提出します。
4. 他の参加者からの一方的な希望や順位が見えないことを確認します。
5. 管理画面で成立候補を確認します。
6. 運営責任者が結果を確定します。
7. スマートフォンで「結果」を開き、確定後だけ結果が表示されることを確認します。

確認すること:

- [ ] 選べる人数と締切が分かる
- [ ] 提出完了が分かる
- [ ] 一方的な希望や順位が相手へ漏れない
- [ ] 運営確定前に結果が表示されない

通知の実送信は、運営責任者が明示的に許可するまで行わないでください。

### ステップ12: 確認結果を提出する

1. 各ステップを`OK`、`要修正`、`確認できず`のいずれかで記録します。
2. 要修正の場合は、問題が起きた画面名を書きます。
3. スクリーンショットを添付します。
4. 「どうなると思ったか」と「実際にどうなったか」を1文ずつ書きます。
5. 本資料の「フロー確定回答」と「正式イベント情報15項目」を記入します。
6. 運営責任者へ提出します。

入力した合成データとLINE連携は、UAT終了後に運営責任者が削除対象として管理します。

## 1. 今回決めること

- 参加者が迷わず最後まで進める順序になっているか
- 画面のタイトル、説明、ボタン名、エラー案内が適切か
- 運営スタッフがスマートフォン中心で対応できるか
- 席案内、希望入力、結果公開、通知のタイミングが運営方針と一致するか
- 2026年8月8日に使用する正式なイベント情報と規約

決済は8月8日の必須導線に含めません。

## 2. 現在の基準フロー

### 参加者

1. 申込フォームを送信
2. LINE本人連携
3. Dreamを登録
4. 席案内5問へ回答
5. SHIME PASSを発行
6. 受付QRを表示
7. スタッフ受付後、公開されたテーブル・席番号をPASSで確認
8. 希望を入力
9. 運営確定後に結果を確認

SHIME診断は任意モジュールです。使用する場合は、どこへ配置するかを確認してください。
Dreamと席案内5問を必須にする場合、PASSより前に完了させる制約があります。

### 運営スタッフ

1. 申込と参加者を確認
2. 本人連携状況を確認
3. QRまたは手動検索で受付
4. 受付済み参加者から席配置案を生成
5. 必要な席を調整・ロック
6. 内容を確認して席を公開
7. 希望受付を開始・締切
8. 成立候補を確認して結果を確定
9. 通知内容と件数を確認して送信

席と結果は、運営責任者の確認前には参加者へ公開されません。

- [ ] 1台だけの場合は、参加者画面と管理画面を交互に開く
- [ ] 画面録画またはスクリーンショットを保存できる

## 8. 問題の報告方法

問題ごとに次の内容を送ってください。

```text
発生日時:
端末とOS:
画面名:
直前に行った操作:
期待した結果:
実際の結果:
再現する・しない:
参加者番号（氏名や電話番号は書かない）:
スクリーンショット:
```

優先度は次の基準で記録します。

- **P0**: 先へ進めない、誤公開、データ消失、他人の情報が見える、当日運営不能
- **P1**: 回避方法はあるが、参加者やスタッフが迷う・負担が大きい
- **P2**: 文言、余白、見た目など、本番後でも対応できる改善

## 9. 確認期限と変更凍結

- 8月5日: 本番相当リハーサル


本資料の承認だけでは本番Goになりません。P0解消、リハーサル、監視、復旧確認を含む最終Go／No-Goを別途行います。

# ワンタップメモ 画面フロー

更新日: 2026-08-05  
状態: N0画面案。UI未実装

## 入口

- PASS画面に、イベントで機能が有効な場合だけ「会話メモ」ボタンを表示する。
- リッチメニューから参加者画面へ戻った場合も同じPASS画面から再開できる。
- 既存participant journeyのDream・質問・診断・PASS順序は変更しない。
- 受付QR発行や受付完了をメモ入力でブロックしない。

## 着席イベント

1. 「会話メモ」を開く。
2. 公開済み会話ペアから相手番号カードを表示する。
3. 相手カードをタップする。
4. 主タグを1つタップすると直ちに保存する。
5. 必要ならお気に入りをタップする。
6. 保存済み表示を確認し、次の相手へ移る。

## 立食イベント

会話相手を自動生成できないため、`self_reported`が承認された場合は次の導線とする。

1. 「話した相手を追加」をタップする。
2. 相手の参加者番号の先頭1文字以上を入力する。
3. 最大10件の番号候補から選ぶ。
4. 「この番号でよい」を確認する。
5. 主タグ画面へ進む。

氏名や連絡先は表示しない。番号を忘れた場合は運営へ確認する代替導線を表示する。

## メモ入力画面

```text
B03との会話で、あなたが感じたこと

[安心した]       [楽しかった]
[共感した]       [もう一度話したい]
[応援したい]     [ご縁なし]

[☆ お気に入り]

保存済み 14:10
```

## モバイル要件

- 320px幅で横スクロールなし。
- ボタン高44px以上。
- 主要タグは2列、長い文言は折返し可能。
- 片手で届く下部に保存状態と「次の相手」。
- タップ直後に選択状態を表示し、通信中は「保存中」。
- 成功は「保存済み」、失敗は「保存できませんでした・再試行」。
- 失敗しても選択状態とスクロール位置を失わない。
- 二重タップは同じPUTとして扱う。

## revision conflict

- 別端末で更新された場合、409受信後に最新値を取得する。
- 「別の端末で更新されました」と表示する。
- 自動で上書きしない。
- 最新値を確認してから再選択する。

## 非公開表示

- 「このメモはあなたにだけ表示されます」を常時表示する。
- 相手への通知、相手からの評価、人気順位に使わないことを明記する。
- 「ご縁なし」を相手や運営通常画面へ表示しない。

## 空状態

- 機能OFF: ボタン自体を表示しない。
- 会話相手なし: 「会話相手が登録されると表示されます」。
- 利用期間終了: 読取のみ許可するか完全非表示かは保存期間決定後に確定する。
- 接触回避対象: 候補に存在したこと自体を示さない。

## E2E受入シナリオ

1. 320pxで8人を連続入力できる。
2. 主タグ変更とfavorite切替が保存される。
3. 通信失敗後に同じ画面で再試行できる。
4. 二重タップで行が増えない。
5. cross-event URLを書換えても404相当になる。
6. 他参加者sessionで本人メモを取得できない。
7. 取消・欠席・接触回避対象が候補に出ない。
8. 立食時の番号前方一致と確認画面が片手で使える。
